# 运行中工具的更新检查

点击托管工具的“更新”时，先检查该工具安装目录中的所有运行实例及附属程序。
检测到运行中的工具后，弹出“关闭工具并更新”确认框，提醒保存内容、结束当前任务。
选择“暂不更新”直接取消；选择“关闭并更新”后请求正常关闭，等待退出，再下载和安装。

正常关闭由工具自身处理，保留其保存提示和退出清理逻辑。DevHub 不强制结束进程。
最多等待 15 秒。取消保存提示、关闭窗口后仅缩到托盘、后台程序没有可关闭窗口，
或附属进程仍然运行时，停止更新，提示手动退出后重试。
请求关闭被系统权限限制拒绝时，也停止更新并显示错误。

直接强制结束可能丢失未保存内容，中断数据库操作、卸载任务或代理连接，
所以确认按钮不会使用强制结束作为兜底。正常关闭也会停止该工具提供的服务，
应先完成当前任务。

后端在下载前和实际覆盖文件前分别检查进程。下载期间重新启动工具时，
拒绝覆盖文件，前端再次请求确认；已经确认的更新若仍遇到运行进程，则报错停止，
避免反复关闭程序。检查及等待在工作线程进行。

进程按安装目录的完整路径匹配，包含子目录中的程序，处理 Windows 大小写和路径前缀。
其他位置安装的同名工具不受影响。检查无法涵盖所有文件占用来源，
例如杀毒软件或安装目录外的进程仍可能导致文件操作失败，原有安装错误仍会显示。

验证包括页面更新分支、取消和重复点击、下载期间启动、退出失败，以及真实 Windows
窗口测试进程的正常退出和拒绝关闭。测试进程与文件均位于工作区。
