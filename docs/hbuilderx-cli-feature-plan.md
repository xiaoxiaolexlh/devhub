# HBuilderX CLI 运行/发行模式计划

## Summary

- 首页新增第三个模式：“HBuilderX CLI”。
- 进入后可在“运行 / 发行”之间切换。
- 第一版只实现“运行 - WEB”；其他运行/发行平台先列出，点击提示“暂未实现”。
- 支持手动配置 HBuilderX CLI 所在文件夹、多项目管理、每个项目独立运行/发行配置、最终命令显示与复制。

## Key Changes

- 新增应用模式：
  - `AppMode` 增加 `hbuilderx-cli`。
  - 首页新增“HBuilderX CLI”卡片。
  - 新增 CLI 工作台页面，顶部提供“运行 / 发行”切换。

- 设置与数据结构：
  - `Settings` 增加 `hbuilderx_cli_dir`，用户填写或选择 `cli.exe` 所在文件夹。
  - `Settings` 增加 `hbuilderx_projects`，每个项目包含 `id`、名称、项目绝对路径、运行配置、发行配置。
  - 运行配置与发行配置完全独立，互不同步。
  - `--project` 参数始终使用项目文件夹全路径。

- 运行 WEB 第一版：
  - 每个项目支持配置 `--browser`、`--ui`、`--compile`、`--continue-on-error`。
  - 生成最终命令：`cli launch web --project <项目全路径> ...`。
  - 支持复制命令、执行命令、展示 stdout/stderr、退出码和错误信息。
  - CLI 路径校验：Windows 查找 `<cli_dir>\cli.exe`，非 Windows 查找 `<cli_dir>/cli`。

- 平台占位：
  - 运行平台列出：手机或模拟器、WEB、小程序。
  - 发行平台列出：Android/iOS 云打包、App 生成本地打包资源、鸿蒙本地打包、鸿蒙生成本地打包资源、App 制作应用 wgt 包、WEB、支付宝小程序、小程序、鸿蒙无服务打包。
  - 除「运行 - WEB」「发行 - App 生成本地打包资源」「发行 - 支付宝小程序」外全部置灰或点击提示“暂未实现”。

- 导入/导出：
  - 支持导出单个项目配置或全部 CLI 配置为 JSON。
  - 导入时保留原项目路径和配置。
  - 如果导入路径在当前电脑不存在，项目仍保留但标记“路径不存在”，用户可重新选择本机路径完成重绑定。
  - 导入合并时按项目 `id` 更新已有项目；新 `id` 追加。

## Test Plan

- 运行 `pnpm build` 做前端类型检查和构建验证。
- 运行 `cargo check` 验证 Tauri 后端编译。
- 手动验证：
  - 未配置 CLI 路径时不能运行，并显示提示。
  - CLI 文件夹无 `cli.exe` 时显示校验错误。
  - 可添加多个项目，每个项目配置互不影响。
  - “运行 - WEB”生成命令包含项目全路径和已开启参数。
  - 复制命令内容与界面预览一致。
  - 执行命令后能看到成功/失败、退出码、stdout/stderr。
  - 导出后再导入能恢复项目与配置。
  - 导入不存在路径时不丢配置，并提示重新绑定路径。

## Assumptions

- 第一版只手动配置 CLI 文件夹，不自动探测 PATH 或安装目录。
- “打开项目文件夹”复用当前已有的工作区窗口能力。
- 发行页第一版只列平台和保留配置结构，不执行发行命令。
- 其他运行平台第一版不执行命令，只提示后续实现。
