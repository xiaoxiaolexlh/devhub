# 快捷面板

应用运行时，默认按 **Ctrl+Alt+Space** 呼出独立快捷面板。再次按快捷键或按 Esc 收起。应用内 **Ctrl+K** 使用相同的入口和启动行为。

- 功能模式来自 `src/lib/modes.ts`，首页、模式切换菜单和快捷面板共享列表。
- 内置工具和自定义工具自动读取工具管理数据。已安装且路径有效时直接打开；未安装、官网下载和路径失效的条目进入工具管理并定位对应卡片。
- 内置工具复用 `tool_launch`；自定义工具复用 `custom_tool_open`，保持工作目录、UAC 和已有实例处理一致。失败保留面板并显示原因，连续点击不会重复执行。
- 支持名称、说明和标识搜索，方向键选择、回车打开、中文输入法组合输入、固定入口和最近使用。历史与固定项在两个面板之间共享。
- 保存工具配置或完成安装更新后刷新入口；每次呼出还会检查当前工具文件。读取工具状态失败会显示错误，模式入口仍然可用。
- 已访问模式保留页面实例和未保存表单，隐藏模式不处理拖放；页面弹窗随模式隐藏。首次进入才加载页面。

在 **应用设置 → 快捷面板** 中配置快捷键、启用状态和关闭行为。快捷键支持 Ctrl / Alt / Shift / Win 加字母、数字、Space 或 F1–F24，必须包含 Ctrl / Alt / Win 中至少一个。注册失败保留原有快捷键和设置；设置写入失败回滚注册。

默认关闭主窗口隐藏到托盘，后台任务继续运行。左键托盘显示主窗口，右键提供主窗口、快捷面板和退出入口。完全退出仍检查 HBuilderX WEB / Node 运行任务，确认并成功停止后才退出。退出后快捷键自动释放。托盘不可用时主窗口关闭使用退出流程。

Windows 快捷键由独立消息线程持有，新组合注册成功且设置保存成功后才释放旧组合；保存失败释放新组合并继续保留旧组合。快捷窗口预先创建且不出现在任务栏；呼出时显示在鼠标所在屏幕。导航通过待处理状态和事件传递，兼容主窗口尚未创建或仍在加载的情况。

## 验证

`node --test tools/test-launcher.mjs tools/test-app-startup.mjs tools/test-tool-cards.mjs tools/test-tool-errors.mjs` 验证入口、共享启动、错误、历史和原有行为。

前端构建完成后运行 `node --experimental-websocket tools/test-launcher-ui.mjs`，使用独立 Edge 配置目录和模拟 IPC 验证实际页面、中文输入法、错误保留、防重复启动、入口同步、页面状态保留、卡片定位及退出确认。截图和结果保存在工作区内 `src-tauri/target/launcher-ui/`。也可用 `DEVHUB_UI_URL` 指定本地开发服务器。

`cargo test --lib hotkey --offline --locked` 验证解析、真实 Windows 快捷键冲突、原组合保留、设置保存失败、释放及消息分发。测试使用 F20–F24 组合，不模拟键盘输入或启动外部工具。

桌面验收应覆盖：其他软件内呼出、多屏缩放、主窗口隐藏后呼出、工具真实启动与 UAC、托盘退出时的任务确认。浏览器中的 IPC 模拟不能代替这些桌面验收。
